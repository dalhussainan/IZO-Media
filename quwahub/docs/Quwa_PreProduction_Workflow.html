# المهمة · المهام الفرعية · المُخرَج المسؤولون المدة
01
البحث والتطوير
بحث معمّق عن الشركة وبناء التصوّر الكامل للحلقة.
  • جمع التاريخ المؤسسي: التأسيس، المحطات، الأزمات، الأرقام
  • مقابلة تمهيدية مع مسؤول التواصل في الشركة
  • حصر الأرشيف المتاح (صور، فيديو، وثائق، قصاصات)
  • تحديد زاوية القصة والخط الدرامي للحلقة
  • كتابة Story Outline موزّع على الفصول الأربعة
وثيقة بحث + ملف القصة (Story Outline)
 RSRDIR ٥ – ٧ أيام
// GATE 01
اعتماد القصة — توقيع DIR + CD
لا ننتقل للتصاريح إلا بقصة معتمدة وزاوية واضحة.
02
الوصول والتصاريح
فتح الأبواب رسمياً: قانونياً وإدارياً وأرشيفياً.
  • صياغة وتوقيع اتفاقية التصوير والظهور الإعلامي
  • تصاريح الوصول للمواقع (المقرات، المصانع، المواقع التاريخية)
  • تصريح استخدام الأرشيف والشعارات والعلامات التجارية
  • تراخيص التصوير الخارجي من الجهات الحكومية إن لزم
اتفاقية موقّعة + قائمة المواقع المعتمدة + تصاريح الأرشيف
 PRODCLIENT ٣ – ٥ أيام
03
اختيار الضيوف والمقابلات التمهيدية
بناء قائمة الشخصيات التي ستروي القصة على الشاشة.
  • ترشيح المؤسسين وكبار الشخصيات والخبراء
  • Pre-interviews هاتفية أو حضورية لتقييم الحضور والقصص
  • ترتيب أولوية الضيوف (أساسي / احتياطي)
  • تنسيق المواعيد المبدئية مع أيام التصوير
قائمة ضيوف معتمدة + ملاحظات المقابلات التمهيدية
 DIRHOSTRSR ٣ أيام
// GATE 02
اعتماد قائمة الضيوف — توقيع DIR + CLIENT
تأكيد موافقة الضيوف الرئيسيين وتوافر مواعيدهم قبل السكربت النهائي.
04
كتابة السكربت التصوّري
تحويل القصة إلى سكربت جاهز للتنفيذ.
  • كتابة المشاهد وفق بنية الفصول الأربعة (الانطلاق، البدايات، المحطات، الإرث)
  • صياغة التعليق الصوتي بخطَّي فهد (فصحى وثائقية) والراوية (كويتية مرحة)
  • إعداد أسئلة المقابلات لكل ضيف
  • بناء Shot List و Storyboard مبسّط للمشاهد الأساسية
  • تحديد مواد الأرشيف والأنيميشن المطلوبة لكل مشهد
سكربت معتمد + Shot List + Storyboard + قائمة مواد الأرشيف
 WRDIR ٤ – ٥ أيام
// GATE 03
اعتماد السكربت — توقيع CD + DIR + CLIENT
توقيع نهائي. أي تعديل بعده يمر بأمر تغيير رسمي (Change Order).
05
الجدولة واللوجستيات
ترجمة السكربت إلى خطة تنفيذ يوم-بيوم.
  • جدول التصوير الكامل (يومان مقدمة + ٥ ضيوف + ٣-٤ خارجي)
  • إصدار Call Sheets لكل يوم تصوير
  • حجز المعدات: كاميرات ARRI، Sony FX6، الإضاءة، الصوت
  • تأكيد الفريق الفني وعقودهم
  • تأكيد مواعيد الضيوف النهائية والمواصلات والإعاشة
جدول إنتاج معتمد + Call Sheets + تأكيدات الحجز
 PROD ٢ – ٣ أيام
06
التجهيز الفني والمعاينة
آخر فحص فني قبل أول يوم تصوير.
  • معاينة المواقع الخارجية (Scouting): الإضاءة، الصوت، الكهرباء، الزوايا
  • تجهيز ركن الشركة في الاستوديو (الديكور والإكسسوار)
  • اختبار الكاميرات والعدسات والإضاءة والصوت
  • بروفة Setup المقابلات (كاميرتين + إضاءة Rembrandt)
تقرير معاينة + موافقة فنية على المواقع والاستوديو
